# XDM 9 beta browser extensions

The ZIP files in this directory are reproducible release artifacts created by
`../scripts/package-extensions.ps1`.

For local Chromium-family browser installation, extract each ZIP, enable
Developer mode on the browser's extensions page, choose **Load unpacked**, and
select the extracted folder. Store-signed packages will be handled separately.

Use `SHA256SUMS.txt` to verify the generated archives.
